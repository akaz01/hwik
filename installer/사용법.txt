Hwik(휙) 사용법
===============

휴대폰과 PC 사이에 사진·파일·글자를 QR 하나로 주고받는 Windows 프로그램입니다.
휴대폰에는 아무것도 설치하지 않습니다.

[설치]
  1. 내려받은 zip을 마우스 오른쪽 단추 > [압축 풀기]로 먼저 풉니다.
     (zip 안에서 바로 실행하면 "python312.dll을 찾을 수 없습니다"라고 나옵니다.)
  2. 풀린 Hwik 폴더 안의 Hwik.exe를 두 번 누릅니다.
  3. [설치]를 누르면 끝입니다. zip과 풀린 폴더는 지워도 됩니다.
     - 관리자 권한이 필요 없습니다.
     - 시작 메뉴와 바탕 화면에 바로가기가 생깁니다.
     - 새 판으로 바꾸기: 새 zip으로 똑같이 하면 됩니다. 설정은 그대로 남습니다.
     - 지우기: 설정 > 앱 > 설치된 앱 > Hwik > 제거

  * Hwik.exe는 Python 재단이 서명한 실행 파일이라 탐색기에서는 Python 아이콘으로 보입니다.
    설치 뒤 생기는 바로가기와 작업 표시줄에는 Hwik 아이콘이 나옵니다.
  * 처음 실행하면 Windows 방화벽이 "액세스를 허용하시겠습니까?"라고 묻습니다. [허용]을 눌러야
    휴대폰이 PC에 접속할 수 있습니다.
    이 창에는 앱 이름이 Hwik이 아니라 "Python"(게시자: Python Software Foundation)으로 나옵니다.
    Hwik.exe가 Python 재단이 서명한 실행 파일이기 때문이며, 그 창이 Hwik의 것이 맞습니다.

[쓰는 법]
  1. PC와 휴대폰을 같은 와이파이에 연결합니다. 와이파이가 없으면 PC를 휴대폰 핫스팟에 연결해도 됩니다.
  2. Hwik을 켜고, 창에 뜬 QR을 휴대폰 카메라로 찍습니다.
  3. 휴대폰 → PC: 휴대폰 화면에서 [사진·파일 고르기]를 누르고 고르면 바로 PC로 옵니다.
     받은 파일은 "받는 곳" 폴더에 저장되고, 사진은 바로 Ctrl+V로 붙여넣을 수 있습니다.
  4. PC → 휴대폰: 창의 [파일 보내기]를 누르거나 파일을 창에 끌어다 놓고, 휴대폰 화면에서 [받기]를 누릅니다.
  5. 글자: PC에서 복사한 글자는 [글자 보내기]로, 휴대폰 글자는 휴대폰 화면의 [PC로 글자 보내기]로 보냅니다.

  * 사진과 파일은 다시 압축하거나 줄이지 않고 원본 그대로 옮깁니다.
  * 아이폰 사진(HEIC)도 받자마자 Ctrl+V로 붙여넣을 수 있습니다. 저장된 HEIC 파일을 Windows에서 열어 보려면
    Microsoft Store의 "HEIF 이미지 확장"이 필요할 수 있습니다(Windows 11에는 대개 들어 있습니다).
  * 창을 닫으면 휴대폰과의 연결이 끊깁니다. 다시 열면 새 QR이 나옵니다.

[꼭 알아 두세요]
  * 집·사무실처럼 믿을 수 있는 와이파이나 내 휴대폰 핫스팟에서만 쓰세요.
    카페·공항 같은 공용 와이파이에서는 쓰지 마세요. 주고받는 내용이 암호화되지 않아,
    같은 와이파이의 다른 사람이 엿볼 수 있습니다.
  * QR에는 이번 연결에만 쓰는 암호가 들어 있습니다. QR 화면을 다른 사람에게 보여 주거나 찍어 올리지 마세요.
  * Hwik은 인터넷의 다른 곳으로 아무것도 보내지 않습니다. PC와 휴대폰 사이에서만 오갑니다.

[안 될 때]
  * 휴대폰에서 화면이 안 열린다: 같은 와이파이인지, 방화벽에서 [허용]을 눌렀는지 확인하세요.
    회사·학교 와이파이는 기기끼리의 연결을 막아 둔 경우가 있습니다. 그럴 때는 휴대폰 핫스팟을 쓰세요.
  * VPN을 켜 두었다면 끄고 다시 해 보세요.
